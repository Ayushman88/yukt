# 0.13.2 Ownership Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every YUKT heap allocation exactly one owner, insert `yukt_release` at drop points, and reject use-after-move, without changing 0.13.1 scalar-record meaning.

**Architecture:** Semantic analysis grows a per-name ownership state machine (Uninit / Owned / Moved). IR gains `Drop`. LLVM lowers `Drop` to `yukt_release`. The process-exit tracker remains a safety net at `yukt_main` return; it is not the owner. Nested heap fields and list-of-owned-element slots are dropped by the runtime from a compiler-inserted release of the parent.

**Tech Stack:** Handwritten C++20 frontend (`yukt_compiler`), LLVM backend (`yukt_backend`), C11 runtime (`yukt_runtime`). No new libraries. No `ref` (0.13.3). No `foreign` / `result`.

## Global Constraints

- Frontend (`compiler/lexer`, `parser`, `ast`, `semantic`, `driver`, `common`, `ir`) must not include LLVM headers.
- Do not invent syntax. Copy the 0.13.2 state machine into `docs/LANGUAGE_SPEC.md` before implementing it.
- No `yukt_release` on 0.13.1 scalar records (integer/float/boolean/nested-plain-record). Assignment still copies bits.
- Allocator caps stay frozen: six classes, four slots, `8948352` bytes (`docs/RUNTIME.md`).
- Parallel thresholds stay `1000000` compile-time work and `100000 * ncpu` runtime tax. Allocating loops stay sequential.
- `benchmarks/results-0.11.json` is not modified.
- Tags `v0.11.0`, `v0.12.0`, `v0.12.1`, `v0.13.1` are not moved.
- Work only on branch `yukt-0.13.2-ownership`. Do not commit to `main`. Do not push. Do not start 0.13.3.
- Independently releasable: every 0.12 / 0.13.1 program that contains no heap-field records keeps its meaning except where today's aliasing of heap pointers was an accident of the tracker (see Locked decisions).
- `./scripts/verify-release.sh` must pass after the slice; extend it to pin `v0.13.1` = `fbc6ff80dc4296ad22e6cbd86b0402d16da97fd6` (annotated tag object) and commit `41f2e0416b8d47fd04ebeac55d9bc6edda9e5cc9`.

## Inventory (this tree, `v0.13.1` / `41f2e04`)

### Allocations that are tracked today

| Producer | Runtime | Kind | Notes |
| --- | --- | --- | --- |
| `zeros(n)`, list literals of i64/f64/bool | `yukt_list_new` | `YUKT_ALLOC_LIST` | header `calloc`; payload size-class / `aligned_alloc` |
| list literals of records | `yukt_list_new_rec` | `YUKT_ALLOC_LIST` kind 5 | stride = record size; payload memcpy of bits |
| `list.copy` / `list.slice` | `yukt_list_clone_range` | new list | **memcpy of payload** — aliases string/list/owned-record slots |
| `str.concat` / `slice` / `repeat` / `join` / split parts | `yukt_str_alloc` | `YUKT_ALLOC_STR` | size-class string cache |
| `str.split` | `yukt_list_new` kind 3 + N strings | list + strings | each part tracked separately |

### Allocations that are **not** tracked

| Producer | Reality |
| --- | --- |
| String literals | LLVM `CreateGlobalString` — immortal globals. `yukt_release` must not `free` them. |
| 0.13.1 records | stack / SSA structs. Nothing to free. |
| Integers, floats, booleans | scalars |

### Drop paths today

- **Only** `yukt_runtime_release` at LLVM `Return` of `main` (`compiler/backend/llvm_backend.cpp` ~496).
- There is **no** `yukt_release`. Overwrite of a list/string local leaks until process exit (tracker still holds the old pointer).
- `yukt_list_set_cstr` / `yukt_list_set_list` / `yukt_list_set_rec` overwrite slots **without** releasing the previous element.

### Compiler facts that the ownership pass must respect

- `Symbol.assigned` is a boolean. `analyze_if` walks then-branch then otherwise-branch on the **same** table — a then-branch move would poison the else-branch. Ownership needs snapshot / restore / join.
- Heap record fields are rejected in `Analyzer::resolve_type_name` (`string` / `list` → `Invalid record`, “wait for 0.13.2”).
- `field_abi` returns false for String/List. Layout must add pointer slots (size 8, align 8) for those fields.
- User calls lower as `IrOp::Call` with pointer args. Passing a list/string into a user function is a **move**.
- Builtins `count`, `say`, index get/set, `list.copy` must be classified borrow vs move (table below).
- `Lowerer::stmts_allocate` already refuses parallelizing allocating bodies. Keep that. Do not insert `yukt_release` inside a parallel body (those bodies cannot allocate, and must not drop either).

### 0.13.x programme (do not expand this slice)

0.13.3 `ref` / 0.13.4 `foreign` / 0.13.5 `result` / 0.13.6 maps stay **out**. Temporary field reads for `say` / `count` / `list.copy` are **borrows of the owner for that statement**, encoded as “owner stays Owned”, not as `ref` syntax.

## Locked decisions (not a redesign — these are the holes the design left for implementers)

1. **String literals become owned by copy.** Binding, passing, or storing `"hi"` copies bytes through a new helper `yukt_str_from_lit(const char*)` that tracks the copy. Drop of that name calls `yukt_release`. The LLVM global is never freed.
2. **Move is a pointer transfer.** `b = a` for heap types: drop previous `b` if Owned; copy the pointer into `b`; mark `a` Moved. No runtime call on the move itself.
3. **Drop is `yukt_release(ptr)`.** For a list, the runtime first drops owned **elements** (string pointers, nested list pointers, or owned fields of kind-5 records), then unregisters the list header and caches/frees the payload. For a string, unregister and cache/free the buffer. Double-release of a still-registered object **traps**. Release of a null pointer is a no-op. Release of a pointer **not** in the tracker traps (compiler bug).
4. **List of heap elements owns the slots.** `items[i]` is a borrow (list stays Owned). `items[i] = v` drops the previous slot then moves `v` in. `s = items[0]` is a **read that copies** only for scalars; for heap element types it is **not** a steal — it is a compile error in 0.13.2 (`Cannot move out of list element`). Use `list.copy` to duplicate the whole list. This matches “no field move-out” for records.
5. **`list.copy` / `list.slice` deep-copy owned slots.** Integer/float/boolean/plain-record payloads stay memcpy. `list[string]`, `list[list[T]]`, and `list[record-with-owned-fields]` must clone each owned child so the copy is a distinct owner. This **fixes** today's accidental aliasing; 0.12 integer-list tests remain bit-identical.
6. **`list.fill` on heap element types clones.** `fill` of `list[string]` / `list[list]` allocates one clone per slot. `fill` of `list[record]` stays a type mismatch (0.13.1 gate). Scalar lists unchanged.
7. **If-join:** snapshot ownership before the `if`. Analyze then, snapshot. Restore, analyze otherwise, snapshot. Join per name: if any path Moved, join is Moved; else if any path Owned, join is Owned; else Uninit. Using a Moved name after the `if` is use-after-move.
8. **Repeat:** moving or dropping a heap name that lives outside the loop, inside the loop, is an error (`Cannot move inside repeat`). First iteration would kill later iterations. Assigning a **new** loop-local heap name each iteration is Allowed (drop at end of iteration). Iterator itself stays integer.
9. **Give transfers.** The callee must not drop the given value. The caller of a function that `give`s a heap value receives Owned. A function that does not `give` its owned locals drops them on every return path.
10. **User function parameters of heap type are Owned (moved in).** Builtins:

| Form | Effect |
| --- | --- |
| `say x`, `count(x)`, `x[i]`, `x[i] = v` (index itself) | borrow; owner stays Owned |
| `zeros`, list/string literals, `str.*` that allocate | fresh Owned |
| `list.copy(x)`, `list.slice(x, …)` | borrow `x`, return new Owned |
| `list.fill`, `list.reverse`, `sort.*` | borrow dest; do not move dest |
| user `create f(items):` with heap param | **move** into `f` |
| `str.len` / `at` / `find` / `contains` / `starts` / `ends` | borrow |
| `str.concat` / `slice` / `repeat` / `join` | borrow inputs, return new Owned |
| `str.split` | borrow input, return new Owned list (list owns the parts) |

11. **Records with only scalar/nested-plain fields** stay 0.13.1 bitwise copy. A record **contains ownership** iff any field's type is string, list, or a record that contains ownership. Moving that record moves all owned fields; one drop of the record drops every owned field. No partial-move records.
12. **No reassignment of Moved names** (`s = zeros(3)` after move is an error), per design.
13. **Debug poison (optional, tests may use tracker counts instead):** `yukt_release` may scribble `0xDD` on a debug build. Prefer a test hook `int64_t yukt_debug_live_allocs(void)` that counts tracker nodes. Do not change cap math.

In `yukt_runtime.c`:

```c
int64_t yukt_debug_live_allocs(void) {
    int64_t n = 0;
    for (YuktAlloc* p = yukt_allocs; p != NULL; p = p->next) {
        n++;
    }
    return n;
}

char* yukt_str_from_lit(const char* s) {
    if (s == NULL) {
        s = "";
    }
    return yukt_str_from_bytes(s, strlen(s));
}

static YuktAlloc* yukt_untrack(void* ptr) {
    YuktAlloc** cursor = &yukt_allocs;
    while (*cursor != NULL) {
        if ((*cursor)->ptr == ptr) {
            YuktAlloc* node = *cursor;
            *cursor = node->next;
            return node;
        }
        cursor = &(*cursor)->next;
    }
    return NULL;
}

void yukt_release(void* ptr) {
    if (ptr == NULL) {
        return;
    }
    YuktAlloc* node = yukt_untrack(ptr);
    if (node == NULL) {
        die("double release or untracked pointer");
    }
    if (node->kind == YUKT_ALLOC_LIST) {
        YuktList* list = (YuktList*)node->ptr;
        /* Task 6 fills owned-element drop. 0.13.1 lists have no owned slots. */
        if (list->data != NULL && yukt_cache_put(yukt_list_bins, list->data, node->bytes)) {
            list->data = NULL;
        }
        free(list->data);
        free(list);
    } else if (!yukt_cache_put(yukt_str_bins, node->ptr, node->bytes)) {
        free(node->ptr);
    }
    free(node);
}
```

Do **not** change bin limits. Reuse the same cache_put path as `yukt_runtime_release`.
